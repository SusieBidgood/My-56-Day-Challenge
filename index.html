Backup & restore

Save a private backup file containing your checklist, weights, body measurements, photos and challenge start date. Keep it somewhere safe, such as a private folder in Google Drive. Your photos and weight information are sensitive, so don't share this file.

Restoring replaces the data currently saved in this app. Back up your current data first. Use Restore only with a backup file you created from this app.

Privacy & saving: Checkmarks, weights and measurements are stored in this browser. Photos are stored on this device using browser storage. This app does not sync between devices or upload your data. Use the Backup & restore buttons regularly and do not clear browser data; browser or device changes could erase your entries. The original challenge start date is kept when you update the app; a new start date is created only if no existing record is found.
